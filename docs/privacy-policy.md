# Politica de privacidad - FitPlan MX

Ultima actualizacion: 2026-06-05

Esta politica describe como FitPlan MX maneja datos personales, datos de salud, fitness, nutricion, ubicacion, imagenes, autenticacion y pagos.

Antes de publicar en Google Play, esta politica debe estar disponible en una URL publica, activa, no geobloqueada y enlazada desde Play Console y desde la app.

## Que datos puede manejar la app

FitPlan MX puede manejar los siguientes datos segun las funciones que use el usuario:

- Datos de perfil: nombre, correo, objetivo, nivel, dias disponibles, lugar de entrenamiento y disciplina.
- Datos de fitness: rutinas, ejercicios, progreso, racha, balance muscular, actividad y registros de entrenamiento.
- Datos de nutricion: comidas, calorias, macronutrientes, hidratacion, notas y estimaciones de porciones.
- Datos de bienestar y salud: peso, glucosa, presion, sueno, energia, sintomas o notas de seguimiento personal.
- Datos de ubicacion: ubicacion aproximada o precisa para registrar recorridos cuando el usuario inicia tracking.
- Imagenes: fotos de comida tomadas por el usuario para estimar macros con Gemini.
- Datos de autenticacion: cuenta de Google si el usuario usa Google Sign-In.
- Datos de compra: estado de suscripcion Premium gestionado por Google Play Billing.

## Para que se usan los datos

Los datos se usan para:

- Mostrar el plan diario y el progreso del usuario.
- Registrar comidas, hidratacion, rutinas, actividad y metricas personales.
- Generar recomendaciones generales de habitos y bienestar.
- Estimar comida y macros a partir de fotos, solo con consentimiento explicito del usuario.
- Generar reportes locales en PDF cuando el usuario lo solicita.
- Gestionar acceso Premium mediante Google Play Billing.
- Mejorar la experiencia local de la app.

## Datos compartidos con terceros

FitPlan MX puede interactuar con:

- Google Gemini / Google AI: procesa texto, datos de seguimiento o imagenes cuando el usuario solicita recomendaciones o analisis de comida. La app muestra consentimiento antes de enviar imagenes/datos de comida a Gemini.
- Google Sign-In: autentica la cuenta del usuario si decide iniciar sesion con Google.
- Google Play Billing: procesa compras y suscripciones Premium.

No vendas datos personales ni datos sensibles de salud.

## Almacenamiento y seguridad

La app guarda datos localmente en el dispositivo mediante almacenamiento privado de Android, bases de datos locales y preferencias. El backup automatico de Android esta desactivado y las reglas de extraccion excluyen bases de datos, preferencias, archivos y almacenamiento externo para reducir el riesgo de respaldar datos sensibles.

## Retencion y eliminacion

Los datos locales permanecen en el dispositivo hasta que el usuario los elimine, borre su perfil local, desinstale la app o use acciones disponibles de limpieza/exportacion. Las compras y suscripciones se gestionan por Google Play.

## Ubicacion

La ubicacion se usa para registrar recorridos de actividad cuando el usuario lo solicita y concede permisos. La app no declara permisos de ubicacion en segundo plano ni foreground service en esta fase.

## Camara e imagenes

La camara se usa de forma opcional para capturar fotos de comida. Antes de enviar una imagen a Gemini, la app pide consentimiento explicito. El usuario puede registrar comida manualmente sin usar la camara ni Gemini.

## Salud y disclaimer medico

FitPlan MX es una herramienta de apoyo para seguimiento personal. No es un dispositivo medico. No diagnostica, trata, cura ni previene enfermedades. No reemplaza atencion medica profesional. Si tienes sintomas, dolor, embarazo, diabetes, hipertension, enfermedad cardiaca u otra condicion medica, consulta a un profesional de salud.
